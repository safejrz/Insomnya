Keep your screen awake on any page — with a single click.

1 Quick Setup

Drag the button below to your bookmarks bar. If your bookmarks bar is hidden, press Ctrl + Shift + B to show it first.

☕
↑ Drag this button to your bookmarks bar ↑

2 Use It

  1. Navigate to any page you want to keep your screen awake on (dashboards, monitoring portals, documentation, etc.).
  2. Click the ☕ Insomnya bookmark in your bookmarks bar.
  3. A small badge appears in the bottom-right corner: ☕ Awake
  4. Your screen will now stay on indefinitely. All page links, buttons, and interactions work normally.
  5. Click the badge to toggle between Awake / Paused.
  6. Click the bookmarklet again to remove the badge completely.

How It Works

  • ✓ Uses the Screen Wake Lock API — the official browser API for preventing sleep
  • ✓ Works on any https:// page — dashboards, portals, monitoring tools, and more
  • ✓ Auto-reacquires wake lock when you switch back to the tab
  • ✓ Zero installation — it's just a bookmark
  • ✓ Does not tamper with page functionality — all links and actions work
  • ✓ Click the badge to pause/resume, click bookmarklet again to remove

Notes

Page navigation: The wake lock stays active as you navigate within a site. If you navigate to a completely different site, click the bookmarklet again on the new page.

Browser support: Screen Wake Lock API is supported in Edge 84+, Chrome 84+, and Opera 70+. Not supported in Firefox.

Secure pages only: The Wake Lock API requires an https:// page. It won't work on http:// or local file:// pages.
